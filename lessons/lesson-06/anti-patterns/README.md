# Zusätzliche Anti-Patterns im WS26

- [AP18: Volume mistaken for backup](AP18-volume-mistaken-for-backup.md) · 24.11.2026

Bearbeiten Sie nur den zugeteilten Fall. Fünf Minuten je Moodle-Gruppe, konkrete Beobachtung und Grenze. Wiederkehrende Fälle werden mit ihrem ursprünglichen Datum benannt. Die Fallnamen ergänzen die vorhandene Sammlung als Lehrfälle; die technischen Eigenschaften sind durch Primärquellen belegt.
