# Abbildungen zu den Beispielen

Die Abbildungen begleiten Build, Start und Beobachtung der Dienste. Lesen Sie sie zusammen mit den Schritten der jeweiligen Anleitung.

| Datei | Was Sie daran erkennen |
|---|---|
| `standard-start.jpg` | Image bauen, Dienst starten und die HTTP-Antwort prüfen. |
| `first-container-console.jpg` | Antworten der Anwendung sowie unterschiedliche Image- und Instanz-IDs. |
| `cache-comparison.jpg` | Wiederverwendete Paketinstallation und veränderter App-/Testschritt. |
| `network-counter-console.jpg` | Der zweite Aufruf erhöht den gespeicherten Counter. |
| `wordpress-browser.jpg` | WordPress mit einem Beitrag aus dem gemeinsamen Compose-Stack. |
| `proxy-browser.jpg` | Ein Host-Port führt über den Proxy zu zwei Diensten. |
| `configuration-console.jpg` | Ein Laufzeitwert verändert die Antwort bei gleichbleibendem Image. |
| `docker-hub-node.jpg` | Repository, Tags und Digest auf der öffentlichen Node-Image-Seite. |

Quelle der Docker-Hub-Abbildung: [Node Official Image](https://hub.docker.com/_/node). Die Oberfläche und Marken gehören den jeweiligen Rechteinhabern. Den verwendeten Basisstand finden Sie im Dockerfile; eigene IDs und Zählerstände ergeben sich aus Ihren jeweiligen Containern.
