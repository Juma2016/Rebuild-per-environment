Continuous Delivery · Beispiel 05

Ein Host-Port, zwei Dienste

Diese Seite liefert Apache. Ihr Browser erreicht sie über den Nginx-Proxy.

Browser :8080 → Nginx :80 → Apache :80

Den zweiten Weg prüfen

/api/ aufrufen: Der Proxy leitet an den Node-Dienst weiter.

/api/health aufrufen: Dort antwortet die Health-Route der Anwendung.

/api/health → nodeapp:3000/health

Was sehen Sie hier?

public-html/index.html ist als schreibgeschützter Bind-Mount im Apache-Service eingebunden. Die Pfadzuordnung steht in nginx.conf. Nur der Proxy veröffentlicht einen Host-Port.
